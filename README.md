# À la conquête de mon corps

Site de l’association ALCC Réflexologie. Elle propose des séances de réflexologie plantaire pour accompagner le corps dans sa capacité à s’autoréguler.

## La réflexologie plantaire

Le pied est la représentation miniaturisée du corps humain. Quelques pressions rythmées, adaptées à chacun, aident le corps à retrouver son équilibre.
